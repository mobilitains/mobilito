{% trans "Count each thing as what it behaves like." %}

{% trans "Pedestrians" %}
{% blocktranslate trimmed %} People walking, wheelchairs, people pushing a bike. A child walking counts; a baby in a pram or stroller doesn't. {% endblocktranslate %}
{% trans "Bikes" %}
{% comment %}Translators: « trottinettes (électriques ou non) », not « scooters », which in French are motor scooters (counted as cars).{% endcomment %} {% blocktranslate trimmed %} Anything that behaves like a bike: bikes, e-bikes, tricycles, kick scooters and e-scooters, skateboards, monowheels. Passengers (a child in a seat or a cargo bike) don't add one. {% endblocktranslate %}
{% trans "Cars" %}
{% blocktranslate trimmed %} Cars, vans, lorries, motorbikes and mopeds: one each, whoever is inside. {% endblocktranslate %}
{% trans "Public transit" %}
{% blocktranslate trimmed %} Each bus or tram, once. {% endblocktranslate %}
