# Mobilito documentation

What's here, and when to read it.

| Document | What it is | Read it when |
|---|---|---|
| [design.md](design.md) | The product specification: what Mobilito is for, who uses it, identity and sign-in, the two observation types, moderation, privacy/GDPR, the data model and what's in v1-preview, v1 and later. Code comments cite it by section (e.g. "§13.2"). | You need to know *why* something works the way it does, or what a feature is meant to do. |
| [roadmap.md](roadmap.md) | The implementation plan, phase by phase, with decisions taken along the way (email provider, map tiles, htmx version…) and the v1-preview and v1 checklists. Finished phases are marked **[COMPLETED]**; open follow-ups are listed under their phase. | You want to know what's done, what's next, or what's been deliberately left for later. |
| [operations.md](operations.md) | How to run the tests, run a development instance, and what we know so far about running it in production. A first draft, with its gaps listed. | You're setting up, testing, or deploying. |
